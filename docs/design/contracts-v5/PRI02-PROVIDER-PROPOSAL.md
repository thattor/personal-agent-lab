## Lifetime and failure contract needed before freeze

managed-inprocess-mock/1 lock death proves only that synchronous Python mock work
ceased. Native subprocess/remote inference can outlive that host. New profile
must distinguish at least never_entered, returned_with_bound_completion,
raised_before_entry, and admitted/unknown. Profile and evidence are persisted at
admission; absent/contradictory session, request or completion bindings fail closed.
TSK's existing Primary charge stays consumed once admission/reservation succeeds;
provider timeout/parse failure is not a refund or new entry permission.

Synchronous invocation may hold the host activity permit across the bounded

provider result + EOF + wait to original attempt. OS PID/process name alone is

Do not widen PRI01.recover_turns or TSK recovery to accept that provider profile
until these provenance/cessation distinctions are independently frozen/tested.
