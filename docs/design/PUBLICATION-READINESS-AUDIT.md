It also does **not** clear the full existing history for publication: raw owner/approval evidence has a real minimization question, screenshot privacy is unreviewed, and imported material needs its existing attribution preserved. These are specific publication-readiness gaps, not assertions that every evidence file is sensitive. Root can decide what intentionally belongs in a public repository and arrange targeted review/sanitized publication; no such action is authorized or performed by this note. Deleting files only at HEAD would leave earlier reachable blobs exposed. No product tests were rerun because no product files changed.
