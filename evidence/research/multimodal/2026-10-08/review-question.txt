Proposed research-stage direction (not adopted implementation):
A. Keep PAL's canonical host/work engine. Add replaceable modality ingress/egress boundaries; avoid a universal new multi-agent/media framework. Choose model transport by VERIFIED capability, not model name.
B. First candidate voice path: explicit bounded recorded turn -> STT final transcript -> existing Primary/host -> committed display response -> TTS. Show interim transcript only; it cannot create a Goal. Preserve audio reference and machine-transcript version when retained; allow natural corrections without confirming every turn. A native realtime voice frontend delegating durable work to PAL is a serious alternative if measured conversational latency/prosody justifies it. Full replacement by one Omni model is not presently justified from docs alone. Do not prematurely prohibit native voice input when prosody/non-speech understanding matters.
C. Images: preserve original user-provided asset and source identity; pass image plus question directly to a qualified vision model. Store OCR/caption/tags as derived hypotheses with source and model/version; use small textual index first, re-open image for detail. Embeddings only if retrieval tests justify them. Tags alone lose spatial/text detail. If Qwen vision transport is unavailable, report unsupported or visibly limited extraction rather than pretending pixels were seen.
D. Video: explicit clip/interval, bounded timestamped frames plus synchronized audio/transcript. Preserve original-relative offsets/crop references/actual sampled intervals and limits. Re-examine a requested interval when needed; never claim unobserved frames/events. Native AV models may implement this capability; a static frame is not a full-video proof. Live camera/screen monitoring is a separate future scope.
E. Minimal logical contract, not a migration plan: conversation references typed media; original asset identity/hash, allowed scope and reference-use state; derived observation references asset + optional region/time + producer/version. Host-only read boundary excludes forgotten originals and all derivatives from context/search/cache reuse; in-flight results fenced. Retaining user raw media does not prove current text sanitization protects embedded secrets. No autonomous personal photo-library import or raw-media cloud upload. Stable-1 has no new gate.
F. Audio playback generation / audible playback / delivered response / Goal completion are distinct. Barge-in stops pending speech; task cancellation requires target-bound host action. Native frontend must not announce work success before receipt, must not write memory/state itself. Output sentence IDs and cancellation/reconnection fences stop stale buffered speech; if exact played span unavailable, mark unknown. Canonical action only from final bounded accepted ingress, and model transcript is interpretation rather than perfect original evidence.
G. Qualification before model/transport adoption: representative real Japanese audio/names/dates/correction/background noise, end-of-speech-to-first-audible-output timing; real image documents/spatial relations/unreadable text, conflicting OCR and source-stop; short video with transient events/audio timing/explicit unobserved gaps; duplicate input, restart, cross-task cancel, revocation while processing, generation/playout separation. Exact finite scenarios and thresholds fixed before execution; no arbitrary soak or user micro-approval. No benchmark claims from this review.
