# PALの画像・音声対応：設計引継ぎ候補 v1

2026-10-08。**受け渡し仕様、30件の評価計画、開発向け文案をまとめた段階。** Opus初回指摘と、本人承認後にSWE-2 Highから受信した指摘を反映した。SWEは600秒で回答途中に終了したため、レビュー全文の取得・最終確認は未完了。

## 何を基準にするか

推論・画像理解は **Qwen3.8-27B** に固定する。画像は原本を保持し、モデルが読める画像として渡す。音声は「録音を文字起こし → PALが解釈・処理 → 保存した返答を読み上げる」とつなぐ。

音声部品の最初の試験候補はQwen3-ASR-0.6BとQwen3-TTS-12Hz-0.6B-CustomVoice。実行エンジンと量子化は実機が用意できた時に決める。別の推論モデルの探索は今回の作業へ広げない。

| 入り口 | PALへの受け渡し | 確かめること |
|---|---|---|
| 画像1枚＋質問 | 元画像と質問を一つの入力へ結び付け、Qwenへ画像を渡す | 日時・数量・位置を読める。不明な内容を作らない。後から選んだ同じ画像を再確認できる |
| 日本語の短い録音 | 録音終了後の最終認識文を通常の入力へ一度だけ渡す | 訂正・否定・固有名を保つ。聞き取った文を表示し、訂正できる |
| 返答の読み上げ | PALが保存した返答本文だけを音声化する | 画面と音声の内容が一致する。停止後に古い音声が再開しない |

キー予約の保存先と、画像・音声受付を文字入力から区別する方法まで具体化した。原本・認識文・返答の対応を残し、再送で仕事が重複しないこと、取消しや「忘れて」が派生結果にも及ぶことを既存のPALへ接続する。

動画・常時録音・連続音声会話は後の拡張対象とする。初期の読み上げは保存済みの会話返答が対象。現在の監査用の通知は参照元を持たないため読み上げず、完了通知の音声化は依存関係を記録できる段階で追加する。
